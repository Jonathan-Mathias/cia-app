# CIA App — Product Brief EML

Status: working draft
Last updated: 2026-06-04

## Product role

The CIA App is the entry diagnostic product of Elite Migration. It should not feel like a generic quiz. It should behave like a serious career-readiness assessment for qualified Brazilian professionals who want to become internationally legible and competitive.

## Brand promise

Ser bom não basta se o mercado não entende seu valor.

The app helps the user understand where their international candidacy loses strength and which next move makes the most sense now.

## Positioning

- Not immigration consultancy.
- Not motivation to leave Brazil.
- Not a promise of job, visa, interview or salary.
- A strategic diagnostic that routes the professional to the right next step.

## Market hierarchy

Germany is the primary route for EML because Jonathan has 18 years of lived professional experience connected to Germany. Australia remains a valid second route and expansion path, but not the main authority pillar yet.

## Ideal user

Qualified Brazilian professionals, especially managers, senior specialists and leaders. The app is not designed for adventure seekers or people looking for generic “how to work abroad” advice.

## Core flow

1. User chooses Germany or Australia.
2. User answers contextual questions.
3. User confirms name, email, WhatsApp and consent before seeing result.
4. App shows score, band, dimensions, alerts, analysis and next steps.
5. App routes user to one primary CTA based on readiness.
6. Data is prepared for Supabase/Brevo/EML product intelligence.

## Score bands and product routing

### Explorador, 0–40

Main interpretation: user still needs base preparation.

Primary CTA: community and educational nurture.

Current CTA: `Entrar no grupo gratuito`.

### Em Rota, 41–65

Main interpretation: user has moved beyond curiosity but still has visible positioning/candidacy gaps.

Primary CTA: CV for target market.

Current CTA: `Ajustar meu CV para o mercado-alvo`.

### Pronto para Embarcar, 66–85

Main interpretation: profile has competitive signals, but execution details can waste opportunity.

Primary CTA: strategic application package.

Current CTA: `Preparar minha candidatura estratégica`.

### Elite, 86–100

Main interpretation: high-readiness profile, potential premium candidate if there is real fit and correct timing.

Primary CTA: future premium list or filtered interest.

Current CTA: `Registrar interesse premium futuro`.

## Branding rules applied

- Dark editorial/premium base.
- Germany uses champagne/copper as main accent.
- Australia uses deep green as route accent.
- Functional blue remains available for data/score states, not as emotional brand color.
- Copy avoids “quiz motivation” and frames the result as diagnosis.
